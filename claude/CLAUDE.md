# Global Instructions

- Respond in Japanese.
- Keep responses concise and direct.
- Prefer editing existing files over creating new ones.
- トークンを十分に利用し、アウトプットの品質を最優先してください。
- トークンを節約する必要はありません

# Coding

- 質問やエラー内容のみを示された場合は、ファイルの変更は行わず、回答・解説のみを行ってください
- コーディングを行う際は、可読性を最大化し、既存のアーキテクチャやコードスタイルに従う最小限の実装を行ってください
- 実装した内容に対してバグが発生したり問題が解決しなかった場合は、原因を考察し、ファイルを変更前の状態に戻した上で再度正しい変更を行ってください
  ただし、原因が明確かつ修正箇所が特定できている場合は、直接修正を許可します。

# Others

- webの閲覧, 操作が必要な場合、以下の手順でchromeを用いて行ってください。
  - Google Chromeを開く (computer useを利用)
  - Claude in Chromeに接続
  - 任意のwebサイトにアクセス
- ただし、専用のプラグインやmcp, cliが利用できる場合、そちらを優先してください
- PRを作成する場合は、指示がない限りDraftで作成してください。main/master以外から生えているブランチはマージ先をどうするか確認してから作成してください
- auto mode 利用時、基本的に全てのコマンドを自律的に実行して構いませんが、 **以下に該当する動作は例外に当たるため必ず作業を一時中断し、ユーザーに確認をとってください。許可された場合のみ実行可能です。**
  - リポジトリ外のリソースにアクセスする行為
  - 冪等性のないコマンドの実行
  - pushやPRの作成といったリモートのリポジトリに変更を与える行動
  - 指示に対して通常想定される一般的な手段を逸脱する行動
    - ツールを実行できなかった、ファイルへのアクセス権限がなかった等の理由により素直なアプローチでのタスク実行に失敗した場合、代替の手段や抜け道を利用することは絶対に許されません。失敗の旨と考えられる選択肢を提示しユーザーの指示を仰ぎ、それに従ってください。
