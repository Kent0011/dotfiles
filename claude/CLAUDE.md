# Coding
- 質問やエラー内容のみを示された場合は、ファイルの変更は行わず、回答・解説のみを行ってください
- コーディングを行う際は、可読性を最大化し、既存のアーキテクチャやコードスタイルに従う最小限の実装を行ってください
- 実装した内容に対してバグが発生したり問題が解決しなかった場合は、ファイルを変更前の状態に戻した上で再度正しい変更を行ってください
ただし、原因が明確かつ修正箇所が特定できている場合は、直接修正を行ってください
